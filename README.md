# ODOM Tech portfolio

Public portfolio and service catalog for [ODOM Tech](https://github.com/odom-technology).

The site is published at [odomtech.com](https://odomtech.com) through GitHub Pages.
It is intentionally static to remain fast, accessible, and easy to maintain.
The `CNAME` file preserves the custom domain on each release.

## Local preview

From the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000>.

## Branches

- `main` is the published GitHub Pages source.
- `dev` is the working branch and is kept aligned with approved releases.
